导入说明

请上传一个Excel文件（.xlsx格式），文件应包含以下列：

  • A列 (必需) - 单词 (title)
  • B列 (必需) - 单词解释 (explanation)
  • C列 (可选) - 备注 (notes)

第一行应为列标题。

注意：导入的单词将自动设置为当前登录用户创建。

示例文件格式

A列: 单词 B列: 单词解释 C列: 备注
apple a fruit that grows on trees red or green fruit
book a set of printed pages used for reading
computer an electronic device for processing data
